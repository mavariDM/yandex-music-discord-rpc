# Яндекс Музыка → Discord RPC

Небольшая Windows-программа: читает трек из медиасессии приложения Яндекс Музыка и показывает его в профиле Discord. Для входа в Яндекс аккаунт и его токен программа не использует.

## Запуск

1. Установи Python 3 для Windows с [python.org](https://www.python.org/downloads/windows/). Во время установки включи `Add python.exe to PATH`.
2. Запусти `start.bat`. При первом запуске введи Application ID Discord-приложения; программа сохранит его локально. Зависимости установятся автоматически.
3. Запусти Яндекс Музыку и включи трек. Discord должен быть открыт на этом же компьютере.

Окно программы должно оставаться открытым, пока работает RPC. Закрытие окна или `Ctrl+C` очищает статус. Настройки хранятся в `%APPDATA%\YandexMusicDiscordRPC\config.json`. При запуске на другом компьютере программа попросит Application ID собственного приложения из [Discord Developer Portal](https://discord.com/developers/applications).

## Если трек не появляется

Программа читает текущую медиасессию Windows, которую публикует приложение Яндекс Музыка. Открой Яндекс Музыку, начни воспроизведение и перезапусти `start.bat`. Если в консоли нет строки `Подключено к Discord RPC`, пришли текст ошибки и версию Windows — подстрою определение сессии.

## Значок в карточке активности

Чтобы Discord показывал значок рядом с треком, загрузи `yandex-music-rpc-icon.png` в **Rich Presence → Art Assets** приложения в Developer Portal. Для asset задай ключ `yandex_music_rpc_icon` (точно так же, с подчёркиваниями). После загрузки перезапусти `start.bat`. Код уже передаёт этот ключ в Discord.

Значок приложения в **General Information** и изображение активности в **Rich Presence → Art Assets** настраиваются отдельно.

Статус также показывает название трека и исполнителя, а Discord получает прогресс воспроизведения, если Windows передаёт длительность трека.
